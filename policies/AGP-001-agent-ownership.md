# AGP-001 - Agent Ownership

Every AI agent must have a named human owner responsible for it. The owner
is the person who approved the agent's use, understands what it's allowed
to do, and is accountable if something goes wrong.

## Required controls

- Record an owner for every agent in the inventory before it goes live.
- Re-check ownership on a regular schedule, and whenever the owner
  changes teams or leaves.
- Suspend or reassign an agent immediately if it has no current owner.
